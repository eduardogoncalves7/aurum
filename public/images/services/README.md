# Imagens dos serviços

Uma imagem por serviço, nomeada com o id do serviço + `.jpg`. O código
procura o arquivo automaticamente — não precisa editar nenhum código pra
adicionar/trocar uma imagem, só substituir o arquivo aqui.

Se um arquivo não existir, o site mostra um fundo dourado no lugar (sem
quebrar o layout).
